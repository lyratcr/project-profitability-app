# StatusBadge
Delta pills and status badges for variance and RAG status.

- Delta: `span.ax-pill` + `.ax-pill-up` (positive) or `.ax-pill-down` (negative), always with the arrow icon and sign; neutral has no modifier.
- Status: `span.ax-badge` with `.ax-dot-positive|warning|negative|info` and a word ("On target", "At risk", "Off track").
- Never rely on the red/green dot alone.
