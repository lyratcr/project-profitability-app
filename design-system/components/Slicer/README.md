# Slicer
Filter controls: a chip group for short lists (≤6 options) and a dropdown for long ones.

- Markup: `.ax-slicer` > `.ax-label` + `.ax-chips` of `button.ax-chip[aria-pressed]`, or `.ax-select`.
- Selected chip = `accent` fill with `on-accent` text. Provide the field label and options.
- Place slicers in a row under the AppShell header, never inside chart cards.
