# PageTabs
Segmented page navigator for Fabric apps and report pages.

- Markup: `.ax-tabs[role=tablist]` > `button.ax-tab[role=tab][aria-selected]`.
- The active tab is raised (`surface-raised`, `shadow-sm`) with a short gold underline. 3–6 pages; use page names, not numbers.
- In Power BI, build with the Page navigator button and the theme colours.
